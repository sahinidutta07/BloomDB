# BloomDB

### AI/ML-Powered DBMS Learning Platform using RAG & Bloom's Taxonomy

BloomDB is an **AI/ML-focused learning platform** for DBMS that combines **Retrieval-Augmented Generation (RAG), semantic embeddings, vector search, and Bloom's Taxonomy classification** to provide context-aware and structured learning.

## AI/ML Pipeline

```text
User Query
    ↓
Query Processing
    ↓
Bloom's Taxonomy Classification
    ↓
Text Embedding
    ↓
Vector Similarity Search
    ↓
Relevant DBMS Knowledge
    ↓
RAG Context
    ↓
LLM Generation
    ↓
AI Answer
```

## Key AI/ML Components

* **Retrieval-Augmented Generation (RAG)** for grounded responses
* **Text embeddings** for semantic representation
* **Vector similarity search** for knowledge retrieval
* **Bloom's Taxonomy classifier** for cognitive-level detection
* **Document chunking and preprocessing** for efficient retrieval
* **LLM-based response generation**
* **ChromaDB** as the vector database
* **Google Gemini** for AI-powered generation

### Bloom's Taxonomy

Queries are classified into six cognitive levels:

**Remember → Understand → Apply → Analyze → Evaluate → Create**

This allows BloomDB to provide learning experiences based on the cognitive complexity of a question.

## Tech Stack

**AI/ML:** Python, RAG, Embeddings, Vector Search, Bloom's Taxonomy, Google Gemini, ChromaDB

**Backend:** FastAPI
**Frontend:** React, TypeScript, TanStack Router, Tailwind CSS, Vite
